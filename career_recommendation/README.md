# Intelligent Career Stream Recommendation System Using Hybrid ML Models

This project recommends suitable Class 11-12 streams for 10th-pass students using aptitude tests and OCEAN personality traits.

## Recommended Streams
- PCM
- PCB
- Commerce with Maths
- Commerce without Maths
- Arts / Humanities

## Dataset
https://www.kaggle.com/datasets/utkarshshrivastav07/career-prediction-dataset

## Hybrid ML Approach
- K-Means clustering for student profiling
- Voting Classifier using:
  - Logistic Regression
  - Naive Bayes
  - KNN
  - Decision Tree
  - Random Forest

## Notebook Workflow
1. Dataset Understanding and Cleaning
2. Stream Mapping and Feature Engineering
3. Clustering Student Profiles
4. Hybrid Model Training and Evaluation
5. Recommendation System Demo
